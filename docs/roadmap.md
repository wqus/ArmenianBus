# План разработки ArmeniaBus

Источники требований: два DOCX-документа из запроса. Они описывают продукт и этапы, но не являются инструкциями для работы с репозиторием. Разработка ведётся отдельными проверяемыми коммитами.

| Этап | Результат | Состояние |
| --- | --- | --- |
| B1 | FastAPI, конфигурация, DB/Redis clients, Alembic, ошибки, logging, health, Docker Compose, CI | Выполнен |
| B2 | Пользователи, регистрация/вход, refresh sessions, роли | Выполнен |
| B3 | Перевозчики, активация, автобусы и места | Выполнен |
| B4 | Рейсы и динамические направления РФ ↔ Армения | Выполнен |
| B5 | Поиск и доступность мест | Далее |
| B6 | Бронирование, 10-минутный hold, конкурентная защита | Ожидает B5 |
| B7 | YooKassa, webhook и идемпотентность | Ожидает B6 |
| B8–B10 | Кабинеты, уведомления, админка, hardening | Позже |
| F1–F10 | Новый frontend и интеграция с API по готовности этапов | Позже |
| D1–D6 | Окружения, доставка, наблюдаемость и запуск | Позже |

В B3 реализованы атомарная регистрация с профилем PENDING, переходы PENDING → ACTIVE ↔ BLOCKED, команда создания администратора, автобусы со стабильными номерами мест и архивирование. Авторство и изменения записываются в аудит. Контракт и ограничения описаны в [carriers-and-buses.md](carriers-and-buses.md).

В B4 реализованы рейсы с динамическими направлениями, временем UTC, ценой Decimal/RUB и переходами DRAFT → ACTIVE → DEPARTED → COMPLETED и ACTIVE → CANCELLED. Принадлежность автобуса перевозчику защищена API и составным внешним ключом БД. Архивация автобуса с незавершёнными рейсами запрещена, в том числе при конкурентном создании рейса. Контракт описан в [routes.md](routes.md).

На B5 нужно добавить публичный поиск по направлению и дате, детали опубликованного рейса и доступность мест. Публичная выдача должна исключать черновики, отменённые и прошедшие рейсы, архивные автобусы и заблокированных перевозчиков. Ограничение критических полей после первого бронирования будет связано с Booking при реализации B6; до этого доступность мест не гарантирует бронирование.
